# 信念發財樹 - 喝水養成遊戲

每一口水，都是對財富的信念灌溉。

## 玩法

- 每喝一杯水，按下按鈕記錄，獲得金幣和財運籤詩
- 每杯間隔 30 分鐘冷卻，防止作弊也符合真實喝水節奏
- 每日目標 8 杯，連續達標可獲得額外金幣加成
- 你的信念之樹會隨著累積喝水量成長

## 使用方式

純靜態 HTML，不需要任何伺服器。直接用瀏覽器打開 `index.html` 即可。

支援 GitHub Pages 部署，開啟後可用手機瀏覽器直接訪問。

## 技術

- 純 HTML / CSS / JavaScript，無任何框架依賴
- SVG 繪製樹木動畫
- localStorage 儲存進度
- 支援瀏覽器通知提醒喝水
